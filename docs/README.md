# Docs overview

This folder contains lightweight documentation files generated or maintained alongside the project.

- **codebook.md** - mapping dictionaries for regions, ranks, and outcomes. Updated manually when we refine groupings.  
- **methods_notes.txt** - automatically generated by `01_cleaning.py`. Summarises scope choices, coverage statistics, limitations, and dropped rows.  
- **figure_captions.txt** - automatically generated by `02_descriptives.py`. One-line captions for each exported figure, ready to paste into the proposal or report.  

## Usage

- Writers should cite **Petram et al. (2024)** for dataset coverage and enrichment when describing the data.  
- Always check `methods_notes.txt` after rerunning the scripts, since percentages and row counts may change if filters or mappings are updated.  
- Captions in `figure_captions.txt` are overwritten each run to match the latest figures in `figures/`.
