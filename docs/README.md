# Docs overview

This folder contains supporting documentation for the project.  

## Files

- **codebook.md**  
  Records the exact mappings used in cleaning and analysis (regions, ranks, outcomes).  
  Ensures results are reproducible and transparent.

- **methods_notes.txt**  
  Short explanations of scope choices, limitations, dropped rows, and fallback rules.  
  Automatically overwritten by the cleaning script on each run.

- **figure_captions.txt**  
  One-line captions for each exported figure.  
  Used when writing the proposal and final report.  
  Automatically updated by the descriptive and modeling scripts.

- **model_notes.txt**  
  Contains notes from predictive modeling (e.g. Random Forest).  
  Summarizes training/test sizes and performance metrics.
